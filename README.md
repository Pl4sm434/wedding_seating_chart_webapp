# Wedding Seating Chart Web App

A responsive front-end web application that allows wedding guests to search for their names and find their assigned table.

## Features
- Search by first name, last name, or full name
- Partial name matching
- Clean and mobile-friendly UI
- Displays matching guest table assignments
- Enter key support for faster search

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the project
2. Open the project folder
3. Double-click `index.html`
